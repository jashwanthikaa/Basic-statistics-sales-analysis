# Sales Data Descriptive Analytics and Preprocessing

## Project Overview

This project performs descriptive analytics and preprocessing on a sales dataset containing information about product volume, pricing, discounts, and net sales value.

The objective of this analysis is to explore the dataset using statistical methods and prepare the data for further analytical modeling.

## Dataset Description

The dataset contains the following key variables:

- Volume
- Average Price
- Total Sales Value
- Discount Rate (%)
- Discount Amount
- Net Sales Value

These variables allow us to analyze pricing patterns, discount strategies, and overall sales performance.

## Objectives

The main objectives of this project are:

- Perform descriptive statistical analysis
- Visualize data distributions using histograms and boxplots
- Identify outliers in the dataset
- Standardize numerical variables using Z-score normalization
- Convert categorical variables into dummy variables using one-hot encoding

## Tools and Technologies

The analysis was conducted using the following tools:

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Key Analysis Steps

### 1. Descriptive Statistics

Basic statistical measures such as mean, median, mode, and standard deviation were calculated to understand the central tendency and variability of the data.

### 2. Data Visualization

Histograms were used to examine the distribution of numerical variables, while boxplots were used to detect potential outliers.

### 3. Standardization

Numerical variables were standardized using Z-score normalization to ensure they have a mean of zero and a standard deviation of one.

### 4. One-Hot Encoding

Categorical variables were converted into binary variables to make the dataset suitable for machine learning models.

## Results

The analysis revealed that several variables such as total sales value and average price exhibit right-skewed distributions, indicating the presence of high-value transactions.

Boxplots also revealed the presence of extreme outliers in certain variables.
